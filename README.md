# 2026-ELC-Starter-Projects

## Goals
- Familiarize yourself with the basics of KiCad
- Learn how to make a schematic and place components into a layout
- Get used to submitting reviews, working on projects outside of workday, and using GitHub

## Repo Instructions
1. Clone the repo to your local machine
   
   ```git clone git@github.com:lhr-solar/2026-ELC-Starter-Projects.git```
2. In the repo, create a new branch with your name and check that the branch exists on the remote repo as well

   ```git checkout -b bevo```
3. Create a new KiCad project inside the folder with your name. When you create the project, make sure you DO NOT check the box that creates a new folder for the project.
4. Push your changes to the remote repository. Here are the commands you'll need to use + a more detailed [github guide](https://app.notion.com/p/lhrs/How-to-Git-3506309905da81729984d78645f975d0?source=copy_link)
   
   ``` git status``` -> Shows you the status report for all the files in your directory. Confirm that you're on the correct branch and NOT MAIN
   
   ``` git add .``` -> Adds all new, modified, and deleted files to the staging area (local action)
   
   ``` git commit -m "wow I made a repo"``` -> Saves a snapshot of the files from the staging area with a message (local action)
   
   ``` git push``` -> Saves the snapshot to the remote repo so everyone else can see your changes (remote action)
   
6. Follow the tutorials and keep learning! Push your changes frequently so you don't accidentally lose your progress if KiCad crashes (trust us on this one... it's not fun)
